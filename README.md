# Application d'inscription au cycle doctoral - USMBA

## Description
Application web qui permet aux candidats de déposer leur dossier d'inscription au cycle doctoral en ligne.

## Acteurs
- Candidat (doctorant)
- Directeur de thèse
- CEDoc
- Administrateur

## Fonctionnalités
- Création de compte et authentification
- Remplissage du dossier d'inscription
- Upload des documents
- Validation par le directeur de thèse
- Vérification par le CEDoc
- Suivi de l'état du dossier
